# だいアリ～ — サイトの方針

`https://daiwata.github.io/` の個人サイト。
うた・楽譜・つくったもの・書きもの を一箇所にまとめるためのページ。

## いちばん大事な制約

**放置しても壊れないこと。** 更新が止まっても費用が発生せず、
何もしなくても表示され続ける状態を保つ。

- `index.html` 1枚で完結。ビルド不要
- 外部依存は Google Fonts、YouTube(押されたときだけ)、Suno(埋め込み曲のみ)に限る
- npm、フレームワーク、CI、いずれも導入しない
- 独自ドメインは取らない(`daiwata.github.io` のまま)
- 月額課金が発生するサービスは、どんなに安くても組み込まない

## あえて入れていないもの（戻さないこと）

- **アクセス解析** — 数字を見ると、書くこと自体が成果を求められる作業に変わってしまうため
- **連絡フォーム** — 外部サービスの登録と管理が増える。連絡はXのDMで足りる
- **メールアドレスの記載** — 収集を避けるため、ページのどこにも書かない

## 書く範囲

「しごと」の節には、経歴と技術スタックだけを書く。
所属先、役職、案件名は書かない。

## デザイン

- 書体は2つだけ。Zen Maru Gothic(見出し・曲名)と Zen Kaku Gothic New(本文)
- 差し色は `--accent: #12807F` の一色のみ
- 意味のない装飾は置かない。背景の模様、英語ラベル、状態バッジは一度入れて全部外した
- ページの「生きている部分」はYouTubeとSunoの曲プレイヤーだけ。再生に必要のない動的要素は足さない

## 曲を追加するとき

「うた」のリストで、YouTubeで公開済みの曲は `<button>`、Sunoで公開済みの曲は
埋め込みプレイヤー、未公開の曲は `<span>` にする。

```html
<!-- 公開済み：プレイヤーで再生できる -->
<button class="title" data-yt="YouTubeの動画ID">曲名</button>

<!-- Sunoで公開済み：曲名の下に埋め込む -->
<span class="title">曲名</span>
<iframe
  class="suno-player"
  src="https://suno.com/embed/Sunoの曲ID"
  title="曲名 — Sunoプレイヤー"
  loading="lazy"
  allow="autoplay"
></iframe>

<!-- 未公開：文字の表示のみ -->
<span class="title">曲名</span>
```

`<span>` を `<button class="title" data-yt="...">` に変えるだけで、
自動的にYouTubeプレイヤーの対象になる。JSの変更は不要。
Sunoの曲は共有URLから曲IDを確認し、`https://suno.com/embed/曲ID` を指定する。

## 進め方

まとめて大きく作り変えるより、小さい変更を気が向いたときに入れる。
手が止まった状態がしばらく続いても問題のない構成を維持する。
